StyleSnap – Hover CSS Inspector & Copier

StyleSnap is a free browser extension for Google Chrome (Chrome Web Store) and Mozilla Firefox for desktop (addons.mozilla.org) for inspecting and copying CSS on the page you choose. Start it with the toolbar button or its keyboard shortcut (Alt+Shift+C by default), hover an element to see its computed styles, colours and dimensions, then click to pin it and copy CSS.

Copy formats include CSS, CSS with descendants and a minimal HTML skeleton, matching accessible :hover rules, utility classes for supported properties, and a JSX style object. Arrow keys navigate elements, Space toggles pinning, C copies CSS and Esc closes the inspector.

All features are free, with no account or usage limit. Processing stays in your browser, with no extension storage, analytics or extension-initiated network requests. Only the output you choose is written to your clipboard.

Computed styles approximate the author’s CSS. The :hover export skips inaccessible stylesheets and does not reproduce the full cascade; utility classes may need adjustment. Browser and store pages (such as Chrome’s own pages, the Chrome Web Store, Firefox’s own pages and addons.mozilla.org) may block inspection, and content inside embedded frames is not inspected.
