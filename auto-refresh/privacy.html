ReloadWatch privacy policy

Publisher: Matheus da Silveira Mello
Contact: matheus.mello.developer@gmail.com
Effective date: 8 November 2026
Applies to: ReloadWatch – Auto Refresh & Change Alert 0.2.0 for Firefox desktop (Firefox 142 or later).

Summary. ReloadWatch reloads pages you choose and checks them for text or element changes inside your browser. It has no account, analytics, ads or remote code, and it sends nothing to the publisher or any third party. Reloads are ordinary visits to the watched website and use your browser's normal cookies for that site.

What is read. On a page you choose to watch, ReloadWatch reads the visible page text and, if you picked an element, that element's text. Matching happens locally in a content script after each load and when the page changes. Only a yes/no result (is your phrase present) and a short fingerprint of the picked element's text are passed to the add-on's background. Page text and cookies are not stored and are not sent anywhere.

What is stored. - Saved rules (page address, match mode, interval, jitter, alert type, watched phrase, element selector, sound, reload limit, active hours) stay in local extension storage until you delete them. There is no automatic expiry. - Live watches (a settings copy, counter, next reload time, element fingerprint) and a picked element (selector and page address) stay in session storage and end with the watch, the browser session or an add-on restart. - Site access you grant is kept by the browser until you remove it. - Storage does not hold page text or cookies.

Deletion. Stop ends a watch but keeps its saved rule, which starts again when its page next loads. Delete rule removes one saved rule and stops watches it started. Delete all ReloadWatch data removes all saved rules, live watches and the picked element and releases site access. Uninstalling removes the add-on's storage.

Notifications. A match shows "ReloadWatch · Match found" with a generic line naming only the site's host (for example "Watched text appeared on example.com"). It never includes the phrase, page text, full address, query string, cookies or credentials. The operating system may keep notification history.

Network. The add-on itself makes no requests to the publisher or any third party (CSP connect-src 'none'). Reloads do request the watched website with your normal cookies, IP address and browser details, governed by that site's own policy. Visiting this policy page or emailing support is separate from using the add-on.

Permissions. - activeTab: act on the tab you clicked from; - scripting: run the page controller and element picker; - alarms: schedule reloads; - notifications: show a match alert; - storage: keep rules and live state locally; - optional site access (http://*/* / https://*/*): requested one site at a time as <scheme>://<host>/* when you start a watch. Denying it starts nothing. In Firefox every watch asks, because Firefox ends temporary access when a page reloads. Nothing is requested at install. No keyboard shortcuts.

Support emails. If you email us, we use your message only to answer you, keep it only as long as needed to handle your request, and delete it within 12 months.

Changes. If this policy changes, the effective date above will be updated.
