PrintTidy – Clean Print & PDF

PrintTidy is a free Firefox desktop add-on that turns a cluttered article into a clean page you can print or save as PDF — layout tools, presets, and HTML or Markdown export, all local.

  • Click the toolbar button on an article; a clean preview opens in a new tab.
  • Change text size, line spacing and typeface; include or hide images; pick margins; show link URLs as footnotes; add a header and footer.
  • Delete paragraphs, images or headings you don’t want (mouse or keyboard, with undo), or edit text on the page.
  • Save layouts as named presets on this device; export as HTML or Markdown.
  • Pages without a clear article offer whole-page cleanup: the original tab with menus, ads and floating bars hidden.

Every feature is free, with unlimited prints. No account, no ads, no tracking. Printing and Save as PDF use Firefox’s own print dialog.

Privacy. Article data is held in session storage for up to 15 minutes on your device. PrintTidy sends nothing to us. The page’s own images and links can still cause traffic to those sites; whole-page cleanup keeps the original tab’s normal network activity. See the privacy policy.

Limits. Add-ons can’t read some pages (for example built-in Firefox pages and addons.mozilla.org). Extraction quality depends on each site’s markup. Desktop Firefox 142 or later only. Not for Firefox for Android. No Chrome, Edge, Opera or Whale claim. No keyboard shortcut is declared.
