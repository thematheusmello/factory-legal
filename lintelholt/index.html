Lintelholt

Lintelholt is a free Firefox desktop add-on that sets, appends or removes HTTP headers with scoped local profiles and a dry-run preview. Everything stays on your device.

  • Create a named profile for the site you are testing. Choose request headers, response headers, or both, then add URL patterns or limit the profile to the current tab for this browser session. Multiple profiles can be enabled together.
  • Lintelholt starts with everything off. Firefox asks for host access when you add a scope. Broad scopes require confirmation and show a warning when active. Preview enabled rules for the current page before turning on the master switch. The toolbar badge shows when a profile has matching rules in the current tab.
  • Save and exchange your profiles as versioned JSON files. Imported profiles stay off until you review them. Profiles and header values are stored on the device.

Every feature is free. No account, no ads, no analytics, no affiliate links and no payments.

Privacy. Profiles, header values, scopes and the master switch stay in local extension storage and are never synced. Tab-only bindings use session storage and expire when the tab or browser session ends. Lintelholt itself makes no network requests and uses connect-src 'none'. Enabled rules change headers on requests to the sites you authorize; those sites receive the headers you configure, under their own policies. See the privacy policy.

Limits. Desktop Firefox 142 or later only. Not for Firefox for Android. No Chrome, Edge, Opera or Whale support is claimed in this Firefox listing. Firefox’s declarative request engine applies the rules; browser restrictions can limit particular headers, and cookie and Host editing are not supported. Lintelholt does not redirect URLs, block requests, rewrite bodies or inject scripts. Preview lists matching rules; it does not inspect live traffic. Use only on sites and systems you may test.
