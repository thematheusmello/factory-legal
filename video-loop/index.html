LoopDeck – A-B Loop & Speed for Video

LoopDeck is a free Firefox desktop add-on that repeats any section of an HTML5 video or audio track — A–B loops, playback speed, a speed trainer, count-in and JSON backup, all local.

  • Start the media, click the LoopDeck toolbar button (or the default shortcut Ctrl+Shift+7, changeable in Firefox), and a small control bar appears on the page.
  • Press [ to set A and ] to set B; the section repeats. Nudge A or B by a tenth of a second.
  • Slow down or speed up from 0.25× to 4×, and keep that speed even if the site’s player tries to reset it.
  • Name and save loops for each page; use the speed trainer, a breathing gap or a four-beat count-in.
  • Export and import your loop library as a JSON file you choose.

Every feature is free, with unlimited saved loops. No account, no ads, no tracking.

Privacy. Saved loops (normalized page address, name, A/B times and speed) and defaults stay in local extension storage on this device. LoopDeck sends nothing to us. Media playback is the website’s own traffic. See the privacy policy.

Limits. Works with standard HTML5 video and audio. Built-in Firefox pages, addons.mozilla.org, closed shadow roots, cross-origin embedded players and some custom players are not supported. It does not download or record media. Desktop Firefox 142 or later only. Not for Firefox for Android. No Chrome, Edge, Opera or Whale claim. Shortcut verified on Firefox on Linux; Settings shows the shortcut Firefox actually assigned.
