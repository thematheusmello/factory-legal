LoopDeck privacy policy

Publisher: Matheus da Silveira Mello
Contact: matheus.mello.developer@gmail.com
Effective date: 9 November 2026
Applies to: LoopDeck – A-B Loop & Speed for Video 0.2.0 for Firefox desktop (Firefox 142 or later).

Summary. LoopDeck does not collect, sell or share personal data. It has no account, analytics, advertising, telemetry or payments, and it makes no network requests of its own. Everything it stores stays in your browser.

What is accessed. Only after you click the LoopDeck toolbar button or press its shortcut, the browser gives temporary access to the current tab. LoopDeck injects its control bar into frames it can reach, finds HTML5 video and audio, and reads or changes playback position and speed for repeats. It does not read page text, forms or passwords, and it does not record or download media. Closing the control bar stops this on that tab. Some pages cannot be accessed (built-in browser pages, add-on store pages, cross-origin embedded players).

What is stored. - Saved loops in browser local extension storage on this device: a normalized page address (fragment removed; query parameters other than v, id, video and episode stripped), the loop name you choose, A and B times, and playback speed. The remaining address can still identify which video or lesson you were practising. - Defaults (playback speed, breathing gap, count-in) in the same local storage. - Which frame of a tab holds the control bar, in session storage until the browser closes. LoopDeck does not use browser sync, so this data is not copied to other devices.

Network. LoopDeck itself sends no network requests to the publisher or any third party (extension pages use CSP connect-src 'none'). Video and audio continue to stream from the website you are watching; seeking or repeating a section can make that site’s player request media again — that traffic is between your browser and the website under the website’s own privacy policy.

Import and export. Export saves your loops as a JSON file wherever you choose; LoopDeck does not send that file anywhere. Import reads only the file you pick, checks it, and merges valid loops into local storage.

Permissions. - activeTab: temporary access to the current tab after the toolbar button or shortcut; - scripting: injects the bundled content.js (control bar) into that tab after that action; - storage: local storage for loops and defaults; session storage for the active frame. No host permissions. No declared content scripts (content.js is injected only after activation). Default attach shortcut: Ctrl+Shift+7 (changeable in Firefox’s Manage Extension Shortcuts). Firefox data collection declaration: required ["none"].

Deletion. Delete a saved loop with its × button in the LoopDeck popup. Removing LoopDeck deletes its stored loops and settings. Exported JSON files are yours to delete.

Support emails. If you email us, we use your message only to answer you, keep it only as long as needed to handle your request, and delete it within 12 months.

Changes. If this policy changes, the effective date above will be updated.
