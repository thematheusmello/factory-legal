Brace Lens

A private JSON viewer for your browser. It turns raw JSON responses into a collapsible, searchable tree, entirely on your device. Free, with no account. The extension does not send document contents or make background network requests.

Effective date: 8 November 2026

Automatic viewing is on by default and uses access to all sites to recognise raw JSON. Firefox additionally changes eligible top-level HTTP(S) JSON response headers so its built-in viewer does not take over; Chrome and Edge do not change headers. See the privacy policy for scope, temporary URL handling and console access.

  • Collapsible tree with colour for strings, numbers, booleans and null
  • Filter keys and values, copy JSONPath or values
  • Large-file mode, JSON Lines, clear error positions
  • Paste viewer, light/dark theme
