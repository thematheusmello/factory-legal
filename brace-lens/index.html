Brace Lens

A private JSON viewer for your browser. It turns raw JSON responses into a collapsible, searchable tree, entirely on your device. Free, no account, no network requests.

  • Collapsible tree with colour for strings, numbers, booleans and null
  • Filter keys and values, copy JSONPath or values
  • Large-file mode, JSON Lines, clear error positions
  • Paste viewer, light/dark theme
