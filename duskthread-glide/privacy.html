Duskthread Glide privacy policy

Effective date: 8 November 2026

Duskthread Glide is published by Matheus da Silveira Mello. For privacy or support questions, write to matheus.mello.developer@gmail.com.

Summary

  • The game has no game account, chat, user-generated content or online leaderboard.
  • Game code contains no separate analytics or tracking service. The inspected build does load CrazyGames SDK v3 from an external server.
  • Progress and settings are saved through the CrazyGames SDK in this build.
  • Gameplay does not request ads. Hosting services and their SDKs have their own data practices.

Save data

The game stores music and sound settings, motion preference, vibration preference, completed courses, selected palette, best scores and furthest progress by mode and assist setting, attempt count, completion-screen status, lifetime distance, spools and runs, and an unfinished run with its route and state so you can continue. Daily score and reach records are each limited to the latest 180 keys. The serialized save is limited to fewer than 64,000 characters.

In the inspected build, saves use CrazyGames SDK data storage under the key duskthread-glide. Its storage location and persistence depend on the SDK and hosting environment. Use the host’s data controls or support to manage platform-held data.

The bundle also contains a browser-storage adapter using localStorage with the same key, but that adapter is not selected by this build. A standalone version using that adapter would save on your device; clearing that site’s browser data would remove its save. This inspected build does not automatically fall back to that adapter if the SDK fails.

Network, platforms and ads

The HTML requests https://sdk.crazygames.com/crazygames-sdk-v3.js, alongside the local game script and stylesheet. Game code initializes the SDK and sends loading and gameplay start/stop signals, and reads and writes saves through it. No separate game-server requests, cookies, analytics calls or score submissions were found in the game code.

The adapter includes interstitial and rewarded-ad methods, but no gameplay code calls them and no ad offer is displayed. This does not determine whether the hosting page or external SDK independently shows ads or processes data.

The external SDK and host may process connection, device, usage or account information under their own policies. Their internal requests, retention and data handling were not verified from the local build. Consult the privacy notice supplied by the platform where you play. A future version for another platform may add that platform’s SDK or save services; those integrations are not present in the inspected files and must be assessed for that version.

Device features and language

Graphics and textures are drawn in Canvas and inline SVG; music and effects are synthesized with Web Audio after interaction. Runtime fonts come from the device; the inspected files contain no remote font, image or audio loads.

Vibration is off by default and is offered only on devices reporting a coarse pointer and supporting the Vibration API. When enabled, it uses short pulses for game events. Motion follows your system’s reduced-motion preference unless changed in settings. The game does not request camera, microphone, location, contacts or notification access.

Six interface languages are bundled. This build’s adapter returns English; it does not read the browser’s locale or obtain a language setting from CrazyGames.

Children

The game is intended for a general audience aged 13 and over and is not directed at children.

Your rights and contact

If you email the publisher, your message and email address are used to answer your request and retained only as long as needed for that purpose. You can request access, correction or deletion of personal data held by the publisher at matheus.mello.developer@gmail.com. For data held by a hosting platform, use that platform’s privacy controls or support. You may complain to the data protection authority in your country.

Changes

Updates will appear on this page with a revised effective date. Hosting-specific disclosures should be checked for the version you play.
