Materials visible in the build

The inspected distribution contains one HTML file, one JavaScript bundle and one stylesheet. Textile scenery, ribbon, hazards, particles and textures are generated with Canvas drawing code. The emblem is inline SVG. Music and sound effects use Web Audio synthesis and a generated noise buffer. No separate image, audio or font files are included. Runtime text uses system font families, including Georgia and serif fallbacks.

Third-party platform software

The HTML loads CrazyGames SDK v3 from https://sdk.crazygames.com/crazygames-sdk-v3.js. The game selects its CrazyGames adapter for initialization, loading and gameplay signals, and save storage. The SDK is external platform software governed by its provider’s terms. Its implementation and licence text are not included in the inspected distribution.

Authorship and verification limits

The handoff credits initial implementation to Codex CLI and subsequent work to Claude Code. Those are handoff attributions; the compiled build alone cannot establish contributor identities, model versions, development history, independent creation or ownership.

The handoff also describes starter-template and build-tool licences, including native tooling dependencies, and font licences for promotional artwork. The cited source reports, dependency notices, font metadata and promotional files are absent from the inspected distribution. Those claims could not be verified here, and no unverified licence text or copyright attribution has been substituted.

Runtime generation of visuals and sound does not by itself establish provenance or distribution rights. The handoff’s blanket claim that no third-party code is shipped does not describe the external CrazyGames SDK loaded by this build. No YouTube Playables or Poki integration was found in these files.
