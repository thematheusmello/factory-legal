Game artwork and sound

Game artwork and sound: textile scenery, ribbon, hazards, particles and textures are generated by the project Canvas drawing code; emblem/icon are project SVG artwork. Music and effects are synthesized with Web Audio oscillators and generated noise, without imported recordings or samples. Repository records document initial Codex CLI development and subsequent Claude Code polish under clean-room instructions. This documents project provenance, not a claim that all inherited code has independently verified authorship.

Shared template

The game uses a supplied shared factory HTML5 template. No upstream source was identified; template authorship provenance has not been independently verified.
