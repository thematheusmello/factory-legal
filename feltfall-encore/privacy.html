Feltfall Encore privacy policy

Effective date: 8 November 2026

Feltfall Encore is published by Matheus da Silveira Mello. For privacy or support questions, write to matheus.mello.developer@gmail.com.

Summary

  • The game is single-player. It has no game account, chat, user-generated content or online leaderboard.
  • Game code contains no separate analytics or tracking service. The inspected build does load CrazyGames SDK v3 from an external server.
  • Progress and settings are saved through the CrazyGames SDK in this build.
  • Gameplay does not request ads, and there are no purchases. Hosting services and their SDKs have their own data practices.

Save data

The game stores unlocked stages; best stars and best clear time per stage, separately for Normal and Assist; death counts and, per stage and mode, the positions of the latest 100 deaths (used only for the results heatmap shown in the game); an unfinished run so Continue can resume it (stage, mode, position, velocity, stage-machinery timers, checkpoint, attempt deaths and hint state); and settings for music, sound effects, reduced motion and haptics. The serialized save is limited to fewer than 64,000 bytes.

In the inspected build, saves use CrazyGames SDK data storage under the key feltfall-encore. Its storage location and persistence depend on the SDK and hosting environment. Use the host’s data controls or support to manage platform-held data. If a save is unreadable or comes from a newer version, the game does not overwrite it; it plays without saving and shows a short notice.

The bundle also contains a browser-storage adapter using localStorage with the same key, but that adapter is not selected by this build. A standalone version using that adapter would save on your device; clearing that site’s browser data would remove its save.

Network, platforms and ads

The HTML requests https://sdk.crazygames.com/crazygames-sdk-v3.js, alongside the local game script and stylesheet. Game code initializes the SDK, sends loading and gameplay start/stop signals, and reads and writes saves through it. No separate game-server requests, cookies, analytics calls or score submissions were found in the game code.

The adapter includes interstitial and rewarded-ad methods, but no gameplay code calls them and no ad offer is displayed. This does not determine whether the hosting page or external SDK independently shows ads or processes data.

The external SDK and host may process connection, device, usage or account information under their own policies. Their internal requests, retention and data handling were not verified from the local build. Consult the privacy notice supplied by the platform where you play. A version for another platform may use that platform’s SDK or save services; those integrations must be assessed for that version.

Device features and language

Scenery, characters and effects are drawn by the game’s own code; music and effects are synthesized with Web Audio. Runtime fonts come from the device; the inspected files contain no remote font, image or audio loads.

Haptics are off by default. When you turn them on and your device supports the Vibration API, the game uses a short pulse when your character is knocked out. Reduced motion is a setting in the game. The game does not request camera, microphone, location, contacts, clipboard, files or notification access.

Six interface languages are bundled. This build’s adapter returns English; it does not read the browser’s locale or obtain a language setting from CrazyGames.

Children

The game is intended for a general audience aged 13 and over and is not directed at children.

Your rights and contact

If you email the publisher, your message and email address are used to answer your request and retained only as long as needed for that purpose. You can request access, correction or deletion of personal data held by the publisher at matheus.mello.developer@gmail.com. For data held by a hosting platform, use that platform’s privacy controls or support. You may complain to the data protection authority in your country.

Changes

Updates will appear on this page with a revised effective date. Hosting-specific disclosures should be checked for the version you play.
