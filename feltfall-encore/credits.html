Game artwork and sound

The theatrical sets, felt and cardboard textures, fox-mask actor, stitched title lettering and promotional compositions were created procedurally for Feltfall Encore. Music and sound effects are original Web Audio synthesis routines; no sample library or external art pack is included. The title lettering uses custom vector strokes, not a font. Promotional covers are compositions, not gameplay screenshots; screenshots and videos show actual gameplay. Repository records document initial Codex CLI development and subsequent Claude Code polish. This documents project provenance, not a claim that all inherited code has independently verified authorship.

Shared template

The game uses a supplied shared factory HTML5 template. At audit time the template contained no licence declaration; no upstream source was identified, and template authorship provenance has not been independently verified. These credits assert no new rights over inherited material.

Fonts

No font files are bundled or downloaded by the game. Text uses system font families requested by name, and each player’s browser chooses an installed font. In the recorded capture environment, interface text resolved to Noto Sans 2.015 and headings to Tinos 1.340; installed font name tables state SIL Open Font License 1.1 (Copyright 2022 The Noto Project Authors; Copyright 2026 The Tinos Project Authors). License: https://openfontlicense.org. Covers and icon contain no font-rendered text. Recorded selection is not a per-glyph certification on every player device, and no font redistribution is claimed.
