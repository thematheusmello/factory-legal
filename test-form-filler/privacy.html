FillPilot privacy policy

Publisher: Matheus da Silveira Mello
Contact: matheus.mello.developer@gmail.com
Effective date: 8 November 2026
Applies to: FillPilot – Test Data Form Filler 0.2.0 for Firefox desktop (Firefox 142 or later).

FillPilot 0.2.0 is a free tool that fills web forms with synthetic test data for QA and development. It has no account, no analytics, no advertising and no server. The publisher receives no data from it.

What it reads, and when. FillPilot reads only when you use it: the popup's "Fill empty fields" button, its keyboard shortcut, or "Fill this form" in the right-click menu. It reads form-field metadata (types, names, ids, labels, placeholders, autocomplete hints) in the top frame of that tab. FillPilot never reads, fills or saves: - password fields, including passwords a page has revealed as plain text when the field is labelled or hinted as a password; - one-time codes; - payment fields such as card number, CVV/CVC, expiry and IBAN; - hidden and file fields; - consent, terms, purchase or subscription checkboxes.

This exclusion is decided from metadata before any value is read. A secret in a field with no recognizable wording or hints, such as an unlabelled password field already revealed as text, cannot be identified. Existing values are never changed.

What it stores, where, and for how long. Everything is kept in the browser's extension storage (storage.local) on this device, not synced and not encrypted: - settings: locale and edge-case mode; - custom rules, exactly as typed; - site profiles, saved only after you read the popup's notice, tick "I understand" and click "Save site profile". A profile holds up to 200 values of the page's visible, eligible text fields and selects plus its checkbox/radio states, keyed by CSS selector under the site's origin. Typed names and e-mail addresses are saved as they are, so capture synthetic data only.

All of it remains until you delete it or remove FillPilot.

Deletion. In Profiles & custom rules: - one site: Delete next to it; - all profiles: Delete all profiles, then click again to confirm; - rules: clear the box and save; - everything: remove FillPilot from the browser.

Profiles saved by FillPilot 0.1.x, which did not skip passwords or payment fields, are marked with a warning. Delete them.

Transmission. None. FillPilot has no network code, and its pages block all connections (connect-src 'none'). Mozilla data_collection_permissions: none.

Websites. FillPilot writes values into the page. The website's own scripts can read them and send them elsewhere, and FillPilot cannot prevent that. FillPilot never submits forms or clicks buttons or links. Use it only on pages you are authorized to test.

Permissions. - activeTab: the tab you act on; - scripting: inject FillPilot's bundled code into that tab; - contextMenus: the menu item; - storage: local data.

There is no host, history, downloads or clipboard access.

Support emails. If you email us, we use your message only to answer you, keep it only as long as needed to handle your request, and delete it within 12 months.

Changes. Changes are published on this page with a new effective date.
