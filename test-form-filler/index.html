FillPilot – Test Data Form Filler

FillPilot is a free Firefox extension that fills web forms with realistic synthetic test data, so you can test sign-up, profile and settings forms quickly.

  • Fill from the toolbar popup, the Ctrl+Shift+L shortcut, or right-click → Fill this form.
  • Consistent personas in six locales (US, UK, Brazil, Germany, France, Spain).
  • Respects field labels, hints, min/max, maxlength and pattern; handles dependent dropdowns.
  • Edge-case mode, custom regex rules and optional per-site profiles.
  • Fills only empty fields, skips passwords, one-time codes, payment and consent fields, and never submits forms.

Every feature is free. No account, no ads, no tracking.

Privacy. FillPilot makes no network requests and sends nothing to us. Settings, rules and profiles stay in your browser. See the privacy policy.
