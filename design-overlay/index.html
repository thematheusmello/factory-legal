OverlayCheck – Pixel-Perfect Overlay

OverlayCheck is a free Firefox desktop add-on that puts your design mockup on top of the webpage you are building, so you can see exactly where the build drifts from the design.

  • Click the OverlayCheck toolbar button on a webpage or a local HTML file to open the overlay panel. Click it again to close it.
  • Choose or drop PNG, JPG or WebP mockups. Each image becomes a layer that is remembered for that page (scheme, host and path; query and hash discarded).
  • Set opacity, X and Y offset and scale. Switch to Difference blend, invert colors, hide layers, or lock a layer so clicks pass through to the page.
  • Drag an unlocked layer into place, or focus the panel and nudge the selected layer with the arrow keys: 1 px, or 10 px with Shift (panel only — not a global shortcut).
  • The Library lists every saved layer grouped by page, deletes layers, and imports or exports layer sets as JSON files. Import appends and does not replace existing layers.

Every feature is free. No accounts, purchases, layer caps, ads, analytics, affiliate links or payments.

Privacy. Mockups and settings stay in this browser profile (IndexedDB and local extension storage). OverlayCheck makes no network requests of its own; the websites you open still load their own resources as usual. See the privacy policy.

Limits. Browser pages (such as about: pages) and sites Firefox protects cannot run overlays. On single-page apps that change the address without reloading, reopen the overlay to load that route’s layers. Desktop Firefox 142 or later only. Not for Firefox for Android. No Chrome, Edge, Opera or Whale claim. No registered keyboard commands.
