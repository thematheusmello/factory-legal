Tickmere

Tickmere is a free Firefox desktop add-on that measures the space on a web page. Draw pixel rulers, inspect an element's box model, drop alignment guides, and copy the measured CSS. Everything stays on your device.

  • Open Tickmere from the toolbar and choose Toggle ruler on this page. Nothing runs in a page until you do. Alt+Shift+M opens the same popup; it does not inject the overlay by itself.
  • Draw as many rulers as you need, move and resize them, and extend guides from their edges. Snap to visible element edges, or turn snap off. Switch units between CSS px, rem and viewport percentages.
  • Inspect shows an element's margin, border, padding and content. Click to pin it, then hold Shift over another element to compare horizontal and vertical gaps or overlaps.
  • Copy CSS writes the measured width and height as a ready-to-paste block. If the browser denies clipboard access, Tickmere shows selectable text instead. It never reads the clipboard.
  • Choose a line colour that suits the page; that preference stays in local extension storage. Escape, the close button, a second invocation or leaving the page removes the overlay and every listener.

Every feature is free. No account, no ads, no analytics, no affiliate links and no payments.

Privacy. Measurements stay in the tab while the overlay is open and are never stored or transmitted. The only stored setting is your ruler colour; it stays in local extension storage and is never synced. Tickmere itself makes no network requests and uses connect-src 'none'. Websites you visit still make their own traffic (analytics, ads); Tickmere does not block or change that. See the privacy policy.

Limits. Desktop Firefox 140 or later only. Not for Firefox for Android. No Chrome, Edge, Opera or Whale support is claimed. Values are CSS pixels, not device pixels (devicePixelRatio is shown; browser zoom changes that relationship). Rem uses the root font size; percentages use the viewport, and copied percentage CSS uses vw/vh. Transformed elements use axis-aligned visual bounds; rotation and skew are approximate. Tickmere measures the top document only: iframe contents, closed page shadow trees and protected browser pages cannot be inspected. Copied CSS is the measured width and height and does not include margin. Continuous page animation is not sampled continuously. There is no screenshot capture or PNG export. Browser pages and add-on stores cannot be measured.
