Mullholt

Mullholt is a free Firefox desktop add-on that arranges your current tab and the next tabs into separate windows on your current screen. Everything stays on your device.

  • Choose equal halves, a wide left or right pane, three columns, or a four-pane grid. Mullholt uses the work area of the screen that contains the current window.
  • Save your own named column widths and reuse them later. Merge the remaining split windows back into one, or use Undo split to restore the previous arrangement. The last five actions remain available until Firefox restarts.
  • Missing tabs open a simple local start page bundled with the add-on. Earlier tabs stay in the first window. Firefox’s minimum window sizes can adjust small panes; the popup tells you when that happens. There is no display picker.
  • Keyboard defaults cover the first four layouts and Undo split: Ctrl+Shift+1 applies 1:1, Ctrl+Shift+2 applies 7:3, Ctrl+Shift+3 applies 3:7, Ctrl+Shift+4 applies three columns, and Ctrl+Shift+U undoes a split. On macOS use Command instead of Ctrl. Remap them in Firefox’s extension shortcut settings if a chord is reserved.

Every feature is free. No account, no ads, no analytics, no affiliate links and no payments.

Privacy. Saved layout names and relative column sizes stay in local extension storage and are never synced. A short undo history is kept in session storage only until Firefox restarts. Mullholt itself makes no network requests and uses connect-src 'none'. It does not read or change page contents. Websites you visit still make their own traffic; Mullholt does not block or change that. See the privacy policy.

Limits. Desktop Firefox 142 or later only. Not for Firefox for Android. No Chrome, Edge, Opera or Whale support is claimed in this Firefox listing. Undo cannot reopen tabs you have closed. New tabs opened after a split are preserved. Browser and operating-system limits can change the dimensions a layout achieves. Physical multi-monitor setups and a display picker are not offered in this version.
