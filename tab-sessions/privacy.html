TabSafe privacy policy

Publisher: Matheus da Silveira Mello
Contact: matheus.mello.developer@gmail.com
Effective date: 9 November 2026
Applies to: TabSafe – Session Saver & Tab Backup 0.2.0 for Firefox desktop (Firefox 142 or later).

Summary. TabSafe saves open tab URLs, titles, pin state and tab-group data in your browser. It has no account, analytics, advertising, telemetry, cloud upload or sync. Restoring tabs opens those websites, which receive normal browser requests including cookies.

What is read. TabSafe reads open tab URLs, titles, pinned state, window order and group names, colours and collapsed state. It does not query the browser history database.

What is stored. Sessions, versions, autosaves and trash stay in local IndexedDB. Settings and a pre-close workspace cache stay in local extension storage. There is no product count limit; records remain until you delete them, subject to disk space. Trash expires after 30 days (checked during library access and autosaves). Removing the extension or clearing profile data can erase everything.

Network. Apart from website loads you start by restoring or opening saved tabs, TabSafe sends no network requests to the publisher or any third party (extension pages use CSP connect-src 'none'). Restoring a session navigates to each saved site with the browser's normal cookies for that site; that site's privacy policy applies.

Exports and backups. JSON exports can include sessions, versions, autosaves and trash; URL exports list addresses from the selected view. Optional daily backups request the Downloads permission when you enable them and write JSON under Downloads/TabSafe/. Denying permission leaves the feature off. Export files remain until you delete them, and device backup tools may copy them — treat them as sensitive browsing information. Disabling backups does not delete existing downloads or revoke permission.

Import. Import accepts URL lists or validated TabSafe session JSON up to 10 MiB and rejects unsafe or oversized files. Current JSON import restores sessions only (not exported histories, autosaves or trash). Privileged about: and file: URLs are skipped on restore and counted.

Permissions. - tabs: read open addresses/titles and restore tabs; - tabGroups: save and recreate groups; - storage: settings and cache; - unlimitedStorage: larger local libraries (subject to disk); - alarms: approximate ten-minute autosaves and daily backups; - optional downloads: write daily backup files after an explicit grant. No host permissions. No registered content scripts.

Deletion. Use the library to delete sessions, clear autosaves, delete versions or empty trash. Export before uninstalling.

Support emails. If you email us, we use your message only to answer you, keep it only as long as needed to handle your request, and delete it within 12 months.

Changes. If this policy changes, the effective date above will be updated.
