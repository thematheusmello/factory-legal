TabSafe – Session Saver & Tab Backup

TabSafe is a free Firefox desktop add-on that saves and restores your browser sessions locally — named sessions, tab groups, pinned tabs, autosaves and a 30-day trash.

  • Save a window or all windows (optionally closing the saved tabs). Shortcut: Ctrl+Shift+7 (tested on Firefox on Linux).
  • Restore into new windows or the current window, including groups and pinned tabs. Update a session and keep version history; revert older versions.
  • Search titles and URLs. Recover deleted sessions from 30-day trash.
  • Autosaves run approximately every ten minutes and on window close while the browser runs.
  • Export JSON or URL lists; import URL lists or validated TabSafe session JSON (up to 10 MiB). Optional daily JSON backups write to Downloads/TabSafe/ after you grant Downloads permission.

Every feature is free. No account, no ads, no tracking.

Privacy. Sessions stay in local IndexedDB on your device. TabSafe sends nothing to us. Restoring tabs opens the saved websites, which receive normal browser traffic including cookies. See the privacy policy.

Limits. Privileged pages such as Firefox about: pages and local files cannot be reopened by extensions; restore skips them and reports how many. Local browser data can be lost — keep independent exports. Tested on Firefox on Linux only.
