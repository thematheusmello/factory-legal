MetaLens – On-Page SEO Checker

MetaLens is a free on-page SEO checker for Firefox desktop (Firefox 142 or later).

Click the toolbar button to audit the page you are viewing:

  • Title (with approximate pixel width), meta description, canonical, robots, language, viewport, word count and social tags
  • Heading outline, missing or multiple H1s and skipped heading levels
  • Images with missing or empty alt text, with on-page highlighting
  • Internal, external and nofollow links; copy them as CSV
  • JSON-LD and microdata, with conservative required-property hints
  • Hreflang codes, x-default and self-reference checks
  • Optional HTTP header check for X-Robots-Tag, Link (canonical) and redirects
  • Export as CSV, JSON or Markdown, or open a printable report and save it as PDF

Every feature is free. No account, no API key, no ads, no tracking.

Privacy. The audit runs in your browser and sends nothing. The optional Check headers button, only when you press it and after you allow access to that site, sends one GET request for the audited page's own address (including its query string) to that same site, without cookies, sign-in details or referrer. Nothing is ever sent to us or any third party. See the privacy policy.

Checks are review hints, not ranking or indexing guarantees. Frames, private windows and protected browser pages are not audited.
