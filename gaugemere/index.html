Gaugemere

Gaugemere is a free Firefox desktop add-on that resizes the current window or viewport to exact device and custom sizes. Everything stays on your device.

  • Open the toolbar button and choose a phone, tablet, desktop or common canvas size, or apply a named custom size. Switch between Window mode (outside dimensions) and Viewport mode (the page area), then rotate with one click.
  • Current window and viewport sizes update while the popup is open. An optional brief badge on the page can confirm the result. You can also use the page context menu.
  • Keep named custom sizes and, if you want, a saved window position. Export your customs as JSON, or import a file you choose (merge, or replace all customs, with an undo copy until you leave the settings page).
  • Keyboard shortcuts: Ctrl+Shift+1 applies 1280 × 800, Ctrl+Shift+2 applies 1440 × 900, Ctrl+Shift+3 rotates the last size, and Ctrl+Shift+Y opens Gaugemere. On macOS use Command instead of Ctrl. Shortcuts can be remapped in Firefox. Firefox may reserve Ctrl+Shift+Y for Downloads; the toolbar button remains available.

Every feature is free. No account, no ads, no analytics, no affiliate links and no payments.

Privacy. Presets, settings, last-used size, favorites and display bounds stay in local extension storage and are never synced. Gaugemere itself makes no network requests and uses connect-src 'none'. Websites you visit still make their own traffic; Gaugemere does not block or change that. See the privacy policy.

Limits. Desktop Firefox 142 or later only. Not for Firefox for Android. No Chrome, Edge, Opera or Whale support is claimed in this Firefox listing. Gaugemere changes dimensions only; it does not emulate a mobile device or change the page’s user agent. Browser minimums and available screen space can limit a requested size. Restricted browser pages allow window resizing, but cannot be measured and cannot show the badge. Viewport mode needs a regular webpage.
