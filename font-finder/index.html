Typeflint

Typeflint is a free Firefox desktop add-on that shows which typeface a web page actually rendered, not just the first name in the CSS font stack, together with that page's typography values.

  • Open Typeflint from the toolbar and choose Inspect this page. Nothing runs in a page until you do.
  • Hover over text to see the rendered face, its size, weight and source. Click to pin a quiet panel with an "Aa" preview, the annotated font stack and the typography values.
  • When the first family in the stack did not render, Typeflint flags the fallback and says why, next to the original stack. Mixed faces on one line are shown separately.
  • Copy CSS writes the element's typography as a ready-to-paste block that keeps the original font stack. Typeflint never reads the clipboard.
  • Page summary lists every face and size pair in the visible text, with element counts. Escape or Close removes the panel and every listener.

Every feature is free. No account, no ads, no analytics, no affiliate links and no payments.

Privacy. Typography values stay in the tab while you inspect and are never stored or transmitted. The only stored setting is whether to show a short guide when inspection starts; it stays in local extension storage and is never synced. Typeflint itself makes no network requests and uses connect-src 'none'. Websites you visit still make their own traffic (fonts, analytics, ads); Typeflint does not block or change that. See the privacy policy.

Limits. Desktop Firefox 142 or later only. Not for Firefox for Android. No Chrome, Edge, Opera or Whale support is claimed. Detection is best effort; generic families are labelled generic because browsers do not reveal the system font behind them; contrast is an estimate, not a certification; frames, pseudo-elements and canvas text are not inspected; the page summary leaves out shadow trees. Inspecting a page does not grant any licence to its fonts. Browser pages and add-on stores cannot be inspected. No keyboard shortcuts are defined by the add-on beyond in-panel Tab, Enter and Escape.
